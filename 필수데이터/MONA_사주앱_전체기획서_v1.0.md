# 모나(MONA) 사주 앱 전체 기획서 v1.0 — 통합본

**문서 버전:** v1.0  
**서비스명:** 모나(MONA)  
**서비스 정의:** 사주와 운세를 바탕으로 오늘의 마음과 삶의 선택을 돌보는 **마음지키미**

---

## 1. 프로젝트 비전

### 1.1 모나가 만들고 싶은 서비스

모나는 단순히 미래를 맞히는 사주 앱이 아니다.

> **행운은 즐기고, 불운은 조심하며,  
> 오늘을 살아갈 작은 여유를 주는 마음지키미.**

운세 결과만 알려주는 것이 아니라,

**운의 흐름을 이해하고 → 지금 마음을 살피고 → 오늘 할 수 있는 작은 행동을 제안하고 → 그 시간을 기록해 주는 앱**

을 목표로 한다.

### 1.2 핵심 브랜드 문장

> **행운은 조금 더 즐겁게,  
> 불운은 조금 더 조심스럽게.  
> 오늘의 마음을 지켜주는 모나.**

---

## 2. 모나의 핵심 철학

기존 운세 서비스가 대체로

**생년월일 → 운세 결과**

에서 끝난다면, 모나는 다음까지 연결한다.

**생년월일 → 사주 → 운의 흐름 → 현재 상황 → 현재 마음 → 현실적인 조언 → 행동 → 히스토리**

모나에게 중요한 것은 단순히 “오늘 운세가 75점”이라고 알려주는 것이 아니라,

> **“그래서 오늘은 어떻게 살아보면 좋을까?”**

에 답해주는 것이다.

### 2.1 모나가 하지 않는 것

- 공포를 이용한 결제 유도
- “큰일 난다”, “반드시 사고가 난다” 같은 위협성 표현
- 결혼·이혼·퇴사·투자 등을 단정적으로 지시
- 운세로 사용자의 성격이나 인생을 절대적으로 규정
- 얼굴 사진만으로 지능·능력·건강·도덕성 등을 단정
- AI가 실제 영적 능력을 가진 것처럼 표현

### 2.2 모나가 하는 것

- 좋은 흐름은 부담 없이 즐길 수 있도록 안내
- 좋지 않은 흐름은 조심할 행동과 선택을 제안
- 사용자의 상황과 감정을 이해한 개인화
- 일상에서 실천할 수 있는 작은 행동 제안
- 과거 고민과 현재 마음을 연결하는 장기적인 기록

|---|---|---|
| 10대 | 공부, 시험, 친구, 부모, 진로 | 공부와 관계 속 불안 |
| 20대 | 취업, 진로, 사랑, 독립, 돈 | 방황과 선택 |
| 30대 | 직업, 결혼, 가족, 주거, 미래 | 미래에 대한 걱정 |
| 40대 | 직장, 자녀, 부모, 경제, 책임 | 책임과 부담 |
| 50대 | 은퇴, 경제, 자녀 독립, 관계 | 변화에 대한 두려움 |

개인화의 기본 단위는 단순한 나이가 아니라 다음 Context로 구성한다.

**나이 + 관계 상태 + 직업 상태 + 가족 상황 + 현재 고민 + 현재 감정**

## 6. 사주 계산의 기본 원칙

사주 계산과 AI 해석은 반드시 분리한다.

```text
사용자 생년월일
        ↓
Calendar / 만세력 Engine
        ↓
사주 원국 계산
        ↓
명리 Factor Engine
        ↓
해석 Rule Engine
        ↓
사용자 상황 Context
        ↓
Mona AI
        ↓
쉽고 따뜻한 설명 + 행동 제안
```

AI가 생년월일을 보고 즉흥적으로 사주팔자를 계산하도록 하지 않는다.

**계산은 코드와 규칙이 담당하고, AI는 설명과 개인화를 담당한다.**

## 7. 명리 Rule Set

사주는 해석 방식과 학파별 차이가 있을 수 있으므로 계산 및 해석 기준을 코드 곳곳에 흩어놓지 않고 독립적인 Rule Set으로 관리한다.

```text
SAJU_RULE_SET
 ├─ calendar_rule
 ├─ solar_time_rule
 ├─ midnight_rule
 ├─ daewoon_rule
 ├─ strength_rule
 ├─ yongsin_rule
 ├─ sinsal_rule
 └─ interpretation_rule
```

결과에는 내부 버전을 저장한다.

```text
Calculation Rule : KR_SAJU_001
Interpretation   : 1.0.0
```

향후 전문가 검토를 받아 기준이 수정되더라도 과거 결과를 추적하고 재현할 수 있어야 한다.

## 15. 신점형 콘텐츠

사용자가 원하는 신점 경험은 유지하되 실제 영적 능력을 주장하지 않는다.

모나에서는 **직관형·감성형 대화 운세**로 설계한다.

예:

- “올해 이직할 수 있을까?”
- “그 사람과 다시 만날까?”
- “앞으로 돈 흐름이 좀 좋아질까?”

내부적으로는 다음을 활용한다.

**사주 + 현재 운 + 사용자 고민 + 현재 감정 + 상담 문맥**

화면 경험은 사주 해석보다 좀 더 직관적이고 감성적으로 제공한다.

## 16. 핵심 기능 ⑦ 모나 마음지키미

모나 앱의 가장 중요한 차별화 영역이다.

### 16.1 모나가 참고할 수 있는 Context

```text
나의 사주
+
오늘 운세
+
대운 / 세운 / 월운
+
관계 프로필
+
현재 상황
+
현재 감정
+
과거 고민
+
이전 모나 상담
```

이를 바탕으로 사용자와 이어지는 대화를 만든다.

### 16.2 모나의 대화 예

사용자:

> “회사 그만두고 싶어.”

좋지 않은 방식:

> “올해 이동수가 있으니 이직하세요.”

모나 방식:

> “요즘 직장에서 마음이 많이 지친 것 같아요. 변화의 흐름은 있지만 감정적으로 바로 결정하기보다 새로운 선택지를 먼저 만들어두는 편이 좋아 보여요. 이직을 고민하게 된 가장 큰 이유가 사람 때문인지, 일 자체 때문인지부터 같이 정리해볼까요?”

모나는 사용자의 결정을 대신하지 않고 **함께 정리해 주는 역할**을 한다.

## 19. 📸 재미로 보는 내 관상

관상은 **사용자 본인의 사진만 사용**할 수 있다.

### 19.1 사용 가능한 사진

- 사용자가 직접 촬영한 본인 사진
- 갤러리에 저장된 본인 사진
- 본인 사진에 필터를 적용한 이미지
- 본인 사진에 스티커를 추가한 이미지
- 본인 사진에 프레임을 적용한 이미지
- 본인 사진에 메이크업 효과를 적용한 이미지
- 색감이나 밝기를 보정한 본인 이미지
- 본인의 얼굴을 기반으로 일반적인 꾸미기가 적용된 이미지

즉, **본인의 사진을 꾸민 이미지는 허용한다.**

### 19.2 사용하지 않는 사진

- 타인의 사진
- 친구·가족 사진
- 연예인·유명인 사진
- 인터넷에서 가져온 제3자의 얼굴 사진
- 본인이 아닌 사람의 얼굴을 관상 분석 대상으로 사용하는 경우

### 19.3 이용 흐름

```text
본인 사진 촬영 또는 선택
        ↓
“본인의 사진이 맞나요?” 확인
        ↓
사진 품질 / 얼굴 확인
        ↓
모나의 재미 관상
        ↓
결과 저장 여부 선택
```

### 19.4 꾸민 사진 처리

꾸민 사진 자체를 이유로 차단하지 않는다.

단, 얼굴 특징을 확인하기 어려울 정도로 가려지거나 변형된 경우 다음과 같이 안내한다.

> “꾸민 사진도 괜찮아요. 다만 얼굴이 너무 많이 가려져 있으면 결과가 부정확할 수 있어요. 얼굴이 조금 더 잘 보이는 사진을 사용해 주세요.”

### 19.5 제공 콘텐츠

- 오늘의 인상
- 오늘의 분위기
- 매력 포인트
- 재미로 보는 얼굴 특징
- 오늘의 이미지 키워드
- 오늘 어울리는 컬러
- 액세서리 또는 패션 TIP
- 모나의 한마디

### 19.6 표현 원칙

관상 결과는 어디까지나 **재미와 엔터테인먼트 목적**으로 제공한다.

얼굴 사진만으로 다음을 사실처럼 판단하지 않는다.

- 지능
- 능력
- 건강 상태
- 도덕성
- 범죄성
- 인간의 가치

### 19.7 사진 개인정보 원칙

가능하면 얼굴 원본 사진은 분석에 필요한 동안만 사용한다.

사용자가 별도로 저장을 선택하지 않는 한 **분석 후 원본 이미지를 보관하지 않는 방향**으로 설계한다.

- 계정 삭제 시 관련 개인정보 정리
- 얼굴 원본 사진은 가능한 한 일시 처리
- 관상 기능에서 본인의 사진만 사용
- 본인 사진을 꾸민 이미지는 허용
- 타인의 얼굴 사진은 관상 분석 대상으로 사용하지 않음

# 37. UX / 디자인 방향

점집처럼 무겁거나 공포스러운 이미지보다 다음을 지향한다.

**따뜻함 + 신비로움 + 친근함 + 작은 즐거움**

# 43. 모나의 장기 데이터 자산

시간이 지날수록 모나의 가장 중요한 자산은 단순한 사주 DB만이 아니다.

```text
사주
+
운의 변화
+
그때 했던 고민
+
그때 느낀 마음
+
모나의 조언
+
시간이 지난 뒤의 변화
```

이 데이터가 쌓이면 모나는

> “오늘 운세는 75점이에요.”

라고 말하는 앱에서

> “몇 달 전에는 이직 문제 때문에 많이 힘들어했는데, 지금은 마음이 조금 달라진 것 같아요.”

라고 말할 수 있는 **장기적인 마음지키미**로 발전할 수 있다.

---

# 44. 모나의 하루 사용자 경험

사용자가 아침에 모나를 연다.

> **좋은 아침이에요. 오늘 마음은 어때요?**

오늘 운세를 본다.

> **오늘은 서두르지 않는 것이 행운이에요.**

출근이나 외출 전에 **나의 패션**을 확인한다.

> **오늘의 컬러 — 네이비**  
> **오늘의 보석 — 블루 토파즈**

낮에는 고민이 생겨 모나에게 이야기한다.

> “회사 사람이 또 신경 쓰이게 해.”

모나는 사용자의 사주·오늘 운세·최근 고민을 참고하여 대화한다.

퇴근길에는 재미로 타로 한 장을 뽑을 수 있다.

밤에는

> **오늘 하루는 어땠어요?**

라는 질문으로 하루의 마음과 경험을 기록한다.

그 기록은 히스토리에 쌓이고 이후 모나 상담에 연결된다.

---

# 45. 모나 v1.0 핵심 정의

> ## **모나는 사주를 이용해 미래를 단정하는 앱이 아니라,  
> 운의 흐름을 이해하고 오늘의 마음과 행동을 돌보도록 돕는 ‘마음지키미’다.**

모나의 전체 서비스는 세 개의 층으로 정리한다.

### 🔮 믿고 보는 운세

**사주 · 운세 · 궁합 · 토정비결 · 이름풀이 · 별자리 · 신점형 콘텐츠**

정확한 계산과 일관된 Rule Set을 기반으로 제공한다.

### 💗 계속 찾게 되는 모나

**마음 체크 · 개인화 상담 · 행동 제안 · 히스토리**

사용자의 오늘과 과거를 연결하는 모나의 핵심이다.

### 🎁 오늘을 즐겁게 만드는 부록

**타로 · 본인 사진으로 보는 관상 · 꿈해몽 · 행운부적 · 나의 패션(Color / 보석) · 행운 뽑기**

가볍게 즐기되 모나의 사주·오행·운세와 자연스럽게 연결한다.

---

# 46. 기획 v1.0에서 확정된 주요 원칙

1. **사주가 모나의 핵심 운세 엔진이다.**
2. 계산은 코드와 Rule Engine이 담당하며 AI가 임의 계산하지 않는다.
3. 운세는 오늘·금주·금월·올해·평생으로 제공한다.
4. 궁합·토정비결·별자리·이름풀이를 핵심 운세 영역에 둔다.
5. 모나 마음지키미를 서비스의 가장 중요한 차별화 기능으로 둔다.
6. 타로는 재미로 카드를 뽑는 부록 콘텐츠로 제공한다.
7. 관상은 부록이며 **반드시 사용자 본인의 사진만 허용한다.**
8. **본인의 사진을 필터·스티커·프레임·메이크업·색감 보정 등으로 꾸민 이미지는 허용한다.**
9. 제3자·친구·가족·연예인·유명인의 사진은 관상 대상으로 사용하지 않는다.
10. 나의 패션을 부록에 포함하고 사주·오행·운세를 Color와 보석/원석에 연결한다.
11. 히스토리는 단순 보관함이 아니라 사용자의 장기적인 삶과 마음의 기록으로 발전시킨다.
12. 행운을 과장하거나 불운으로 공포를 유발하지 않는다.
13. 운세 결과의 마지막에는 가능한 경우 오늘 실천할 수 있는 작은 행동을 제안한다.
14. 사용자의 중요한 현실적 결정을 운세가 대신하지 않는다.
15. 모든 기능은 최종적으로 **“오늘의 마음을 지켜주는 모나”**라는 브랜드 철학에 맞춰 설계한다.
