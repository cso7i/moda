# ocr

STRICT_QA v2 OCR 작업 산출물을 관리합니다.

## 관리 원칙
- 책별 하위 폴더를 사용합니다.
- 50페이지 단위 누적 Excel을 기준 파일로 관리합니다.
- 실제 판독 작업은 기본 5페이지 단위로 진행하고 다음 1페이지 경계를 확인합니다.
- 처리 상태는 `OCR완료=Y`, `판독완료=N`, `확정판독=공란`으로 구분합니다.
- 중국 고전 세로조판은 각 열 위→아래, 열 진행 오른쪽→왼쪽으로 판독합니다.
- 기존 누적 영역의 값/스타일/행높이/이미지를 보존합니다.
- validation JSON과 handoff 기록을 함께 관리할 수 있습니다.

## 권장 구조
`ocr/<순번>_<서명>/`
