# MODA 원전 OCR 저장소

이 저장소는 MODA 원전 OCR 및 데이터화 작업을 관리합니다.

## 폴더
- `original/` : 정본 원전 파일과 원본 이미지 관련 자료
- `ocr/` : STRICT_QA v2 OCR 작업 Excel, 검증 기록, 누적 결과

## 공통 원칙
- 정본 원전이 최종 판독 기준입니다.
- 중국 고전 세로조판은 각 열 위→아래, 열 진행 오른쪽→왼쪽으로 판독합니다.
- 기존 전사나 관용 문구로 정규화하지 않고 판면을 우선합니다.
- OCR 작업은 기본 5페이지 단위로 수행하고, 다음 1페이지까지 경계를 확인합니다.
- 누적 Excel은 기존 완료 구간을 보존하고 새 구간만 추가합니다.
